# Campaign timeline

Authoritative in-fiction chronology lives at [campaign/timeline.md](../../campaign/timeline.md). One row per canon delta, columns: *In-fiction date* (Faerûn DR calendar) / *Event* / *Session*. Entries are appended chronologically by in-fiction date, not by session number; the file is updated after each `/draft` acceptance as part of the recap pipeline.

Consult it before answering any question involving campaign dates, travel time, downtime, or event ordering — do not attempt to reconstruct the timeline from session files or memory. Related: [[calendar-notes]] for the real-world/in-fiction date log at `sessions/inputs/calendar.md`.
