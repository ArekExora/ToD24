The published *Tyranny of Dragons* module (Hoard of the Dragon Queen + Rise of Tiamat) is the campaign's reference adventure, but the actual campaign **deviates from it**. Player choices have shifted events away from the canonical path.

**Why:** The GM wants to run a responsive campaign, not a rails adventure — faction behavior should follow from what the factions actually know in this campaign's timeline, not from what the module assumes will happen.

**How to apply:** Treat `campaign/timeline.md` and faction files at `campaign/factions/<name>.md` as authoritative for current state. When reasoning about "what would the Cult do?", ground the answer in their tracked knowledge and the actual timeline — do not assume scripted events from the published module have happened. Flag clearly when a suggestion would only make sense under module-canon assumptions.
