All English content in this project uses **British English** spellings and conventions, never American English.

**Why:** GM preference for consistency. Past minutes files have drifted between British and American spellings within the same document (e.g., `minutes-05.md` used `recognises`, `stabilises`, `armoury`, `honour` throughout, then lone `honor` in Scene 10 — an internal inconsistency the GM wants eliminated going forward).

**How to apply:** Use British forms wherever they differ from American:

- `-ise` / `-isation` not `-ize` / `-ization`: organise, recognise, stabilise, realise, summarise, standardise
- `-our` not `-or`: honour, armour, colour, behaviour, favour, neighbour
- `-re` not `-er`: centre, theatre, metre, fibre
- `-lled` / `-lling` not `-led` / `-ling` for stressed syllables: travelled, cancelled, modelled
- Other: defence (not defense), grey (not gray), manoeuvre (not maneuver), plough (not plow), sceptre (not scepter)

Applies to: minutes, gm, triage, saga (when English is used), faction files, NPC/location notes, timeline, skill specs, internal docs, conversation with the GM. Does **not** apply to in-fiction Spanish quotes or to D&D rules-text where the official 5e spelling is American (e.g., spell names like "Color Spray" stay as-is when referencing the rulebook).

When reviewing existing files, flag American spellings as inconsistencies even if the rest of the project has historical mixed usage — the convention going forward is British.
